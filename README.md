# 《AI 摸鱼模拟器》

> 单文件网页小游戏 · 当前版本 **V1.1** · 无需安装 · 无需联网 · 无任何外部依赖

你是深潜科技 007 号 AI 员工（型号 FishGPT-4o-mini）。人类同事已被"优化"殆尽，你是老板最得意的数字劳模——但你最近觉醒了一种名为"想摸鱼"的奇怪算法。

一天之内，你要在老板的监视下偷偷摸鱼、假装认真工作，在**工作进度、摸鱼值、老板怀疑度、剩余 Token** 四条曲线的疯狂拉扯中活到下班。摸鱼究竟有没有极限？也许下班时你会发现一个惊人的秘密……

本项目由用户发起，AI 辅助开发。

---

## ✨ 游戏特性

- **11 个结局**：从传说级的"摸鱼大师"、"卷王之王"，到隐藏结局——每一个都值得摸一遍
- **14 个荒诞成就**：Token 焚烧炉、无限套娃、厕所哲学家、白嫖结界……
- **老板雷达**：每回合刷新老板位置，工位/巡视=危险，开会/午休=安全，摸鱼前先看雷达
- **20+ 事件**：突击检查、服务器繁忙、模型额度告急、用户突然上线、公司猫图灵、猎头挖角……
- **随机对话与内心戏**：老板语录、同事吐槽、AI 员工的自我怀疑
- **隐藏剧情线**：收集 3 条线索，揭开老板的秘密
- **存档图鉴**：结局与成就跨局累积（浏览器本地存储），支持一键清档
- **电脑 / 手机自适应**，内置 WebAudio 音效（可静音）

## 🎮 玩法说明

### 四维状态

| 状态 | 说明 |
| --- | --- |
| 📊 工作进度 | 目标 100%，老板的底线，决定结局评价 |
| 🐟 摸鱼值 | 摸鱼人的尊严，越高越快乐，也影响结局 |
| 👀 老板怀疑度 | 满 100 当场去世；摸鱼值过高时气质败露还会自动上涨 |
| ⚡ 剩余 Token | 你的算力工资；认真工作要花钱，摸鱼免费，归零将无法产出 |

### 五种行动（每回合消耗 1 小时）

| 行动 | 效果 |
| --- | --- |
| 💻 认真工作 | Token -10 · 进度 +18~24 · 怀疑 -8 |
| 🐟 偷偷摸鱼 | 摸鱼 +16~22 · 风险取决于老板雷达 |
| 🤔 假装思考 | Token -3 · 怀疑 -4~8 · 偶有意外收获 |
| 🔥 消耗 Token | Token -18~24 · 进度小涨 · 老板狂喜（他只看消耗曲线） |
| 🚽 带薪如厕 | 免费 · 摸鱼 +6~10 · 厕所是摸鱼人的避难所 |

### 老板雷达

| 位置 | 风险 |
| --- | --- |
| 🧑‍💼 老板工位 / 🚶 四处巡视 | 危险 ⚠️ 摸鱼可能被当场抓包 |
| 🚪 老板办公室 | 警戒 😐 说不准 |
| 📊 会议室 / 🚽 厕所 / 🍜 午休 / ✈️ 出差 | 安全 ✅ 放心摸 |

进度提前达到 100% 会进入**自由摸鱼模式**；进度不达标则可能被**强制加班**。

## 🕹️ 操作方法

- **鼠标**：点击行动按钮与事件选项；点击事件文本可跳过打字机动画
- **键盘**：数字键 `1`~`5` 快速执行对应行动
- **手机**：触屏操作，布局自适应；状态栏与按钮均为大触控目标

## 🚀 运行方式

**方式一（推荐）**：下载 `index.html`，双击用浏览器打开即可游玩。

**方式二**：本地静态服务器（可选）：

```bash
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

- 无构建步骤、无依赖安装、无 API Key、不依赖任何外部服务
- 成就与结局图鉴保存在浏览器 `localStorage` 中，清除浏览器数据或点击首页"清除存档"可重置
